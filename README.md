# JTG Frontend Home Assignment

Responsive portfolio landing page recreated from the supplied Figma screenshot using plain HTML, CSS and vanilla JavaScript.

## Run
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Structure
- `index.html` — semantic page markup
- `css/style.css` — responsive styles and illustration
- `js/script.js` — mobile navigation, active section tracking, testimonial controls, back-to-top and contact form behavior

## Notes
Project photos and testimonial avatars are loaded from remote image URLs. Replace the sample portfolio copy, contact details and links with your real information before publishing.
